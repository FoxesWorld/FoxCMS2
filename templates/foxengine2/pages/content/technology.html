Architecture

FoxesCraft 3.0

Интерфейс и серверное ядро построены вокруг Vue 3, типизированных контрактов, явного application bootstrap и ограниченных JSON API.

Обновлено: 30 июля 2026 года

Клиентский runtime

  • Vue 3 и Composition API.
  • TypeScript strict mode.
  • Vite production build с lazy routes.
  • Vue Router и адаптивная дизайн-система.

Backend core

  • Явный Application bootstrap вместо глобального service locator.
  • HttpRequest и UserSession передаются через конструкторы.
  • Детерминированный JSON-manifest модулей.
  • Prepared PDO-запросы и session-bound CSRF.

Данные и безопасность

  • Whitelist JSON bootstrap без password hash и серверных секретов.
  • Credentials загружаются только из environment variables.
  • Единый same-origin API client.
  • Автоматический secret scan и запрет удалённых runtime-сигнатур.

Контроль качества

  • Typecheck и production build.
  • PHP parser и проверка архитектурных контрактов.
  • Asset/API/removed-runtime gates.
  • Нулевой legacy audit и bundle budget.
